result. Fill them from `bin/run-metrics <session.jsonl>`: *Planning (adj.)* is the adjusted wall
time (gaps over 5 min flagged AFK? and capped), *Round trips* is user turns, *Empty* is empty
model responses (stalls). *Min per ralph pass* is the wall time of each `ralph/once.sh` pass.
A cap that is exceeded twice on different scenarios is a candidate for a prompt change; note
the change in the last column.
